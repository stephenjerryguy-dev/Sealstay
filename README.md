# SealStay

Verified student housing for SGU students in Grenada.

SealStay is a Vite + React app with:

- A cinematic landing page inspired by the original Figma Make concept
- Searchable rental listings by neighborhood, price, walk time, and Seal Approved status
- Listing detail pages with map context, SealScore, and related rentals
- Student, landlord, admin, claim-listing, and list-property flows
- Vercel SPA routing configured for `sealstay.xyz`

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The app is configured for Vercel through `vercel.json`; production output is written to `dist`.
